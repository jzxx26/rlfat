1. Speech production & short-time analysis

Lungs → vocal folds → vocal tract → speech. Voiced: periodic, pitch; unvoiced: turbulent, high ZCR. Formants are vocal tract resonances. Frame N=Fs×duration; hop H=Fs×shift; overlap=N−H; frames=floor((L−N)/H)+1. At 16 kHz, 20 ms and 10 ms: N=320,H=160,overlap=160; one second gives 99 frames. x=[1,2,1,−1,−2,−1,1,2]: energy Σx²=17; sign crossings=2; ZCR=2/8=.25 (or 2/7 with pair normalization). R(k)=Σx[n]x[n+k]; R0=17,R1=8,R2=−6. Pitch=Fs/pitch lag; 8000/40=200 Hz. Hamming w[n]=.54−.46cos(2πn/(N−1)); N=8 gives w0=.08,w1=.2532. Multiply sample by window. FFT spacing Fs/NFFT; power=|X|².

3. LPC, LPCC & PLP

LPC predicts current sample from prior samples. Levinson–Durbin positive predictor convention: E0=R0; ki=(Ri−Σ old a_j R(i−j))/Eprev; new a_j=old a_j−ki old a_(i−j); a_i=ki; Ei=(1−ki²)Eprev. R=[10,6,3,1]. Iteration 1: k=.6,a=[.6],E=6.4. Iteration 2: k=(3−.6×6)/6.4=−.09375; a=[.65625,−.09375],E=6.34375. Iteration 3: k=(1−.65625×3+.09375×6)/6.34375=−.06404; a=[.65025,−.05172,−.06404],E≈6.3177. Update simultaneously. LPCC c1=a1; c2=a2+a1²/2; general c_m=a_m+Σ(k/m)c_k a_(m−k), k=1..m−1 for m≤p. a=[.4048,−.1387] → c2≈−.0568. PLP: power → Bark filtering → equal loudness → cube root → inverse transform/autocorrelation → LPC → cepstrum. P=[113.16,12.41,4.53] times Bark [.8,1,.7]→[90.53,12.41,3.17]; times loudness [.5,1,1.2]→[45.27,12.41,3.80]; cube roots [3.56,2.32,1.56]. 4. ASR, LVCSR, CNN/RNN, CTC & Whisper

MAP W*=argmax P(X|W)P(W). ON .65×.30=.195; OFF .8×.25=.20 → OFF. LVCSR recognizes continuous speech: coarticulation, segmentation, large vocabulary. Acoustic model handles sounds, language model context, pronunciation lexicon maps words to phones. CNN input 32×20×1, 8 filters 3×3, stride 1, padding 0: output 30×18×8, parameters (3×3×1+1)×8=80. General output floor((I−F+2P)/S)+1. RNN h=tanh(Wx+Uhprev+b); sequential context, BPTT; LSTM handles longer dependencies. CTC: choose max at each frame; merge consecutive duplicates BEFORE removing blank. c,c,a,t→cat; path probability .6×.5×.7×.6=.126. b,o,blank,o,k→book. Total label probability SUM over all paths yielding label. Greedy path not necessarily globally best label. Whisper: log Mel spectrogram → Transformer encoder → autoregressive decoder. Multilingual transcription, translation, language ID; hallucination and compute limitations. No blank-collapse CTC decoder.

6. Language models, HMM and Viterbi

Unigram, bigram, trigram: P(w|history)=count(history,w)/count(history). Add-one=(count+1)/(count(history)+V). Multiply conditional probabilities; perplexity=P(sequence)^(−1/N), e.g. P=1/24,N=4→2.213. HMM: hidden states, observations, initial π, transitions A, emissions B. Viterbi → best path → MAX. Forward → all possible paths → SUM. Example π=[.6,.4], first emissions [.5,.2], A=[[.7,.3],[.4,.6]], second emissions [.1,.8]. Initial [.3,.08]. Viterbi next [max(.21,.032)×.1,max(.09,.048)×.8]=[.021,.072], backtrack state1→state2. Forward [.0242,.1104], sum=.1346. CRF log-scores add rather than multiply; decode best sequence using transition+emission scores.

12. Summarization, MT, topic modeling, QA and RAG

Extractive selects existing sentences; abstractive generates. Frequency score sum word frequencies: AI=3,model=2,data=1; 'AI model'=5 vs 'AI data'=4. TF-IDF sentence ranking, graph TextRank, position scores. RNN encoder→context→decoder; LSTM gates; attention weighted context; Transformers parallel encoding. ROUGE-1 recall overlap/reference count; 'AI improves search' vs 'AI improves retrieval'→2/3. MT source→encoder→context/attention→decoder→target; rule/statistical/neural approaches; BLEU modified ngram precision and brevity penalty. Topic modeling unsupervised: LDA document-topic and topic-word distributions; NMF factorizes nonnegative matrix; topic coherence. QA knowledge graph queries vs retrieval/extractive spans vs generative answers. RAG: chunk→embed→index→retrieve relevant chunks→augment prompt→generate. Benefits grounding and updated knowledge; failures poor retrieval, hallucination, stale index. Fine-tuning changes model weights; RAG adds external knowledge at inference.
